Calculator Programs



This is where you can find programs and games I've written for calculators.

Credits for these images are at the bottom of the page.

Program Platform Language Description
TimeCALC TI-82, TI-83 TI-Basic A simple time conversion program for TI graphing calculators.
DisplayCharacter82 TI-82 Z80 Assembly A TI-82 assembly program that lets you cycle through all 256 characters in the character set of the TI-82
TIDICE TI-82, TI-83, TI-83+, TI-84+, TI-84+ CE TI-Basic A 6-sided die probability program written in TI-BASIC
Guess Number ICE TI-84+ CE ICE Compiler This is a number guessing game for the TI-84 Plus CE that I wrote using the ICE Compiler
Standard Form Circle Equation Generator TI-84+ CE TI-Basic This program takes 3 inputs (H, K, and R) and uses them to generate a circle equation in standard form.
Error Magnitude Calculator TI-84+ CE TI-Basic This program calculates the magnitude of error between two given values.
Error Percent Calculator TI-84+ CE TI-Basic This program calculates the percentage of error between two given values.
Fibonacci Sequence TI-84+ CE TI-Basic This program calculates all the numbers in the Fibonacci sequence and displays them.
Midpoint Calculator TI-84+ CE TI-Basic This program takes X and Y values for two points and calculates the midpoint between them.
Pythagorean Theorem Calculator TI-84+ CE TI-Basic This program takes A and B values and outputs the C value for the Pythagorean theorem (c=hypotenuse of a right triangle, a and b are the legs)

The programs written in TI-Basic should run on any calculator that supports TI-Basic programs. The text may appear wonky due to differences in screen size between different calculators.
